# RepoAtlas

Turn a public GitHub repository into an interactive map of its modules, classes,
functions and dependencies — for TypeScript, JavaScript, Python, Go, Java, C#, Rust,
PHP, Ruby and C/C++.

> Working name. This repository currently contains only the design docs; the code is
> built milestone by milestone following `docs/ROADMAP.md`.

## Start building with Claude Code

1. Put these files in an empty git repository and commit them.
2. Run `claude` in the repository root.
3. Prompt: *"Read CLAUDE.md and all files in docs/. Then start Milestone 0 in
   docs/ROADMAP.md. Stop after M0's acceptance check and summarize."*
4. Review, commit, then continue one milestone at a time.
